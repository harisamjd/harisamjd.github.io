# Design System

## Portfolio Website — Haris A. Majid

**Version:** 1.0

---

# 1. Design Philosophy

The design should feel timeless.

Avoid trends that will quickly become outdated.

The experience should communicate professionalism through simplicity rather than decoration.

Every visual element should have a clear purpose.

Design Inspirations

* Apple
* Linear
* Vercel
* Stripe
* Notion
* Raycast

Core Principles

* Simplicity
* Consistency
* Spaciousness
* Readability
* Performance
* Elegance

---

# 2. Visual Identity

* Professional
* Minimal
* Calm
* Premium
* Intelligent
* Modern

Avoid

* Heavy gradients

# 26. Motion Philosophy

Motion should support storytelling.

Motion should never compete with content.

Every movement must communicate something.

The user should notice the story, not the animation.

---

# 27. Design Principles

Whenever there is uncertainty, follow these priorities:

Readability over decoration.

Whitespace over density.

Consistency over creativity.

Content over visuals.

Performance over effects.

Accessibility over aesthetics.

Simplicity over complexity.

A beautiful portfolio is not the one with the most animations.

It is the one where every visual decision feels intentional and effortless.
